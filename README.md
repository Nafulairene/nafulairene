## 🧠 How I Think About Support Engineering

<div align="center">

| | |
|:---:|:---|
| **1. DIAGNOSE** | Find the root cause, not just the symptom |
| **2. SOLVE** | Fix it for this client, right now |
| **3. EDUCATE** | Train the client so they can self-serve next time |
| **4. DOCUMENT** | Write it down so the next engineer doesn't guess |
| **5. AUTOMATE** | Build it so nobody has to solve it again |

<br/>

*The best support engineers don't just reduce ticket volume —*
*they make their customers more technically capable.*

**That's the difference between closing a ticket and closing the gap.**
